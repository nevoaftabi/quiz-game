# Trivia Game

Trivia Game is a full-stack quiz app where users sign in, choose a category and difficulty, complete a quiz, and review past games.

The app pulls questions from the Open Trivia Database, scores each game, and saves results so users can see their history, accuracy, and question-by-question performance.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Node.js
- Express
- PostgreSQL
- Clerk
- Zod

## What It Does

- Authenticated quiz flow with Clerk
- Custom quiz setup
- Trivia questions from Open Trivia Database
- Scoring and answer review
- Persistent game history in PostgreSQL
- History stats like accuracy, correct/incorrect counts, and average questions per game

## Why It Matters

This project shows a complete product flow:
- frontend UI
- backend API
- authentication
- database persistence
- user-specific history
